# 최민영 풀스택 포트폴리오

컴퓨터소프트웨어과 졸업 과제용 포트폴리오입니다. GitHub Pages로 배포할 수 있게 정적 사이트로 빌드합니다.

프로젝트는 세 개입니다.

- 가면가: [minsung6167/gmg](https://github.com/minsung6167/gmg)
- 곁: [soldesk7/gyeot](https://github.com/soldesk7/gyeot)
- AI 캐릭터 게임: [alstjdalsdud12/vibe-coding-project](https://github.com/alstjdalsdud12/vibe-coding-project)

서비스 주소는 아직 없습니다. 세 프로젝트 모두 로컬 실행이고, 캐릭터 게임의 발표 자료만 GitHub Pages에 있습니다.

## 로컬 실행

```bash
npm install
npm run dev
```

개발 서버는 [http://127.0.0.1:4327](http://127.0.0.1:4327) 에서 열립니다.

## GitHub Pages

1. 이 저장소를 GitHub에 올립니다.
2. Settings → Pages → Source를 GitHub Actions로 둡니다.
3. `main`에 올리면 워크플로가 정적 사이트를 배포합니다.
4. 저장소 이름이 `username.github.io`이면 주소는 `https://username.github.io/` 입니다.
5. 그 외 저장소면 주소는 `https://username.github.io/저장소이름/` 입니다.
