# 풀스택 포트폴리오

컴퓨터소프트웨어 전공 졸업 과제용 풀스택 개발자 포트폴리오입니다. GitHub Pages로 배포합니다.

들어 있는 프로젝트는 세 개입니다.

- gmg
- RE_cook
- vibe-coding-project

첫 화면에서 역할과 세 프로젝트로 들어가고, 각 사례는 개요, 문제, 맡은 일, 화면, 서버와 데이터, 기술 선택, 문제 해결, 검증, 결과 순서로 읽습니다. 서비스 주소는 각 프로젝트를 배포한 뒤에 연결합니다.

이름, 메일, GitHub, 기술 이름, 사례 본문은 확인된 내용만 이어서 채웁니다.

## 로컬 실행

```bash
npm install
npm run dev
```

개발 서버는 [http://127.0.0.1:4327](http://127.0.0.1:4327) 에서 열립니다.

## GitHub Pages

1. 이 저장소를 GitHub에 올립니다.
2. 저장소 Settings → Pages → Source를 GitHub Actions로 둡니다.
3. `main`에 올리면 워크플로가 정적 사이트를 배포합니다.
4. 저장소 이름이 `username.github.io`이면 주소는 `https://username.github.io/` 입니다.
5. 그 외 저장소면 주소는 `https://username.github.io/저장소이름/` 입니다.
